# Accessibility Writing Standards

Content standards for accessible interface writing, mapped to WCAG 2.2.

These are generalized patterns from production work on financial services
interfaces. Product-specific copy and internal terminology are excluded.

## Contents

- [Error messages](error-messages.md)
- [Link text](link-text.md)
- [Instructions and labels](instructions-and-labels.md)

## How to use this

Each document covers one content pattern: the failure mode, the fix, the
WCAG criteria it maps to, and before/after examples.

WCAG references are to normative success criteria text at w3.org
